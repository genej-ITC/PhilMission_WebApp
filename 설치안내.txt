필리핀 선교 웹앱 설치 안내

[접속 주소]

GitHub 배포 주소:
https://genej-itc.github.io/PhilMission_WebApp/

기존 배포 주소:
https://philmission-webapp.goodlake6.chatgpt.site

위 주소 중 하나를 열면 됩니다. 로그인 없이 사용할 수 있습니다.
한 주소에 접속할 수 없으면 다른 주소로 접속하세요.
TXT 파일 자체가 앱은 아니며, 접속·설치 방법을 안내하는 파일입니다.

[안드로이드]

1. Chrome 앱을 직접 엽니다.
2. 위 주소 중 하나를 주소창에 붙여 넣습니다.
3. 오른쪽 위 ⋮ 메뉴 → 설치 및 바로가기 만들기 → 설치를 누릅니다.
   버전에 따라 앱 설치 또는 홈 화면에 추가로 표시됩니다.
4. 홈 화면의 필리핀 선교 아이콘을 눌러 실행합니다.

[아이폰]

1. Safari 앱을 직접 엽니다.
2. 위 주소 중 하나를 주소창에 붙여 넣습니다.
3. 공유 버튼(□↑) → 홈 화면에 추가를 누릅니다.
4. 웹 앱으로 열기가 보이면 켜고, 추가를 누릅니다.
5. 홈 화면의 필리핀 선교 아이콘을 눌러 실행합니다.

[참고]

카카오톡이나 ChatGPT 안에서 링크를 여는 대신,
Chrome 또는 Safari를 직접 실행해 설치하세요.

처음에는 인터넷에 연결해 기본 자료를 저장하세요.
더보기 → 설치·오프라인에서 저장 상태를 확인할 수 있습니다.

두 주소는 기기에 저장하는 공간이 서로 다릅니다.
개인 연락처·즐겨찾기·등록한 파일은 자동으로 공유되지 않습니다.
다른 주소로 옮길 때는 기존 앱의 설정 → 백업 저장 후,
새 주소의 앱에서 설정 → 백업 복원을 사용하세요.
